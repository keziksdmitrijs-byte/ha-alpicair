# AlpicAir Modbus

Кастомная интеграция Home Assistant для рекуператоров AlpicAir/MCB с Modbus TCP.

## Возможности

- Выбор режима: Standby, Защита здания, Эконом, Комфорт, Интенсивный обдув.
- Switch ночного охлаждения через Coil 4.
- Интенсивный обдув через Coil 5.
- Выключатель Standby через holding register 1.
- Кнопка сброса ошибок через holding register 202.
- Единая целевая температура для активного режима.
- Настройки расписания и температур ночного охлаждения.
- Настройки расхода приточного и вытяжного воздуха для четырёх ступеней.
- Температурные сенсоры и расчётный КПД теплообменника.

## Установка через HACS

1. В HACS откройте `Integrations`.
2. В меню выберите `Custom repositories`.
3. Добавьте репозиторий `https://github.com/keziksdmitrijs-byte/ha-alpicair` с категорией `Integration`.
4. Установите **AlpicAir Modbus**.
5. Перезагрузите Home Assistant.
6. Откройте `Настройки → Устройства и службы → Добавить интеграцию`.
7. Найдите **AlpicAir Modbus** и укажите IP-адрес, порт, Slave ID и смещение адресации.

## Адресация

В Modbus-документации адреса часто начинаются с 1, а библиотека Modbus может ожидать адреса с 0. Поле **Смещение адресации** задаёт это поведение:

- `0` — использовать адреса из таблицы как есть;
- `1` — вычесть 1 из каждого адреса перед отправкой контроллеру.

Начните с значения `0`. Если чтение возвращает некорректные значения, отключите интеграцию, измените смещение на `1` и выполните проверку снова.

## Важные регистры

| Функция | Тип | Адрес |
|---|---|---:|
| Режим системы | Holding register | 1 |
| Comfort temperature | Holding register | 2 |
| Economy temperature | Holding register | 4 |
| Building protection temperature | Holding register | 6 |
| Night cooling | Coil | 4 |
| Intensive air flow | Coil | 5 |
| Alarm reset | Holding register | 202 |
| Supply airflow stages | Holding registers | 450–453 |
| Extract airflow stages | Holding registers | 456–459 |

## Проверка перед эксплуатацией

Интеграция управляет вентиляцией. Перед постоянным использованием протестируйте чтение и запись на конкретном контроллере, особенно:

- смещение адресов Modbus;
- полярность Coil 4 и Coil 5;
- корректность работы Standby;
- реакцию устройства на интенсивный обдув;
- возможность одновременной работы ночного охлаждения и интенсивного обдува.
